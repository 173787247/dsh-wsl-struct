# dsh-wsl-struct

> **语言：** **中文**（本页） · [English](./README.en.md)

沙箱化 **jq / yq / sqlite3（只读）**，限制根目录与输出长度。

## 工具

| 工具 | 作用 |
|------|------|
| `struct_status` | CLI 是否在 PATH |
| `struct_jq` | jq 过滤文件或内联 JSON |
| `struct_yq` | yq 查 YAML |
| `struct_sqlite` | 仅 `SELECT` / `WITH` / `PRAGMA table_info` |
